# Customer Segmentation in Marketing with Python

This project explores customer segmentation using **K-Means** and **Hierarchical Clustering** to identify distinct customer groups and optimize marketing strategies.

##  Objective
To analyze how acquisition channels and geographic factors influence student engagement and learning outcomes on an online learning platform.

##  Dataset
The dataset is based on an onboarding survey of customers and includes:
- Country of residence
- Customer lifetime value
- Engagement metrics
- Acquisition channel (e.g., YouTube, Facebook, etc.)

##  Technologies Used
- Python 3.x
- pandas, NumPy, matplotlib, seaborn
- scikit-learn
- scipy

##  Steps Performed
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. K-Means clustering
5. Hierarchical clustering
6. Visualization and interpretation of clusters

##  Insights
- Identified key customer segments based on engagement and lifetime value.
- Found geographic trends in acquisition channels (e.g., YouTube vs. Facebook).
- Provided recommendations for personalized marketing strategies.

##  Files
- `Customer Analytics Segmentation Project Solution.ipynb`: Main analysis notebook.
- `customer_segmentation_data.csv`: Dataset used for analysis.
- `Segmentation data legend.xlsx`: Data dictionary describing variables.
